BLE 列印測試 · receipt-engine

Web Bluetooth → ESC/POS → 熱感打印機。需要 Chrome 或 Edge + HTTPS,手機或桌機都可以(電腦需有藍牙 BLE)。Safari / Firefox 不支援。

1 · 設定 Setup

佳博便攜機沒有切刀,profile 已設 supportsCut: false,不會送出切紙指令;列印後送紙 12mm。

2 · 連線與列印 Connect & print

Connect 必須由你按下才會跳出裝置選擇器(瀏覽器規定)。連上後可直接按任一列印按鈕。
